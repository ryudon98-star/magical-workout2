# 魔法学校の家トレ記録アプリ

## 内容
- index.html：家トレ記録アプリ本体
- manifest.webmanifest：ホーム画面追加用の設定
- sw.js：アプリ画面のキャッシュ
- icon-192.png / icon-512.png：アプリアイコン

## Androidで使う方法
1. ZIPを解凍し、フォルダ内のファイルをまとめて保管してください。
2. PWAとしてホーム画面に追加するには、HTTPS対応のWebサイトにこのフォルダの中身をアップロードし、そのURLをChromeで開く必要があります。
3. Chromeのメニューから「アプリをインストール」または「ホーム画面に追加」を選んでください。

注意：スマホ内の file:// から直接 index.html を開くだけでは、Service Workerによるオフラインアプリ機能や通常のPWAインストールは動作しない場合があります。
記録のバックアップは、アプリ内の「バックアップを書き出す」から定期的に保存してください。
